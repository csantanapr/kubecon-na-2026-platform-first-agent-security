# Stage deck

Present from `platform-first-agent-security-slim.html` in this folder, or from
the slides site:
[csantanapr.github.io/kubecon-na-2026-platform-first-agent-security](https://csantanapr.github.io/kubecon-na-2026-platform-first-agent-security/)

It is the full stage deck: 15 slides, staged click reveals, speaker notes in the
presenter view (press `S`), and works offline from `file://`. The "slim" name is
left over from an older 13.5 MB build that embedded simulated demo videos. That
build is retired: each demo slide now carries a terminal replay of the live EKS
run instead (press `T` on the slide, arrow keys to run each command, `Esc` to
close).

The slides site is published from the `gh-pages` branch, which holds a copy of
this file as `index.html`. Republish it after changing the deck.
